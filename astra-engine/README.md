# Движок Астры

Стиль монтажа «Астра»: Астра (GPT-6 через локальный сервис Codex) пишет монтаж кодом из готовых кубиков, сама смотрит черновик и правит его. Движок — Remotion (React → MP4).

## Устройство

| Папка | Что там |
|---|---|
| `src/kit` | Кубики: камера, субтитры по словам, текст за спиной, заголовок, плашка, панель, карточка, иконка, фото, стрелка, вспышка, звуки. Анимации, шрифты и звуки уже настроены. |
| `src/montage/Montage.tsx` | Проверочный монтаж для Studio. Для каждого ролика его заменяет файл, который пишет Астра. |
| `knowledge/` | Учебник Астры: как монтировать (`director.md`), справочник по кубикам (`kit.md`), образцы монтажа (`examples/`). |
| `director/` | Цикл: задание → монтаж → проверка кода → вырезка автора → черновик → Астра смотрит кадры → финал. |
| `matting/cutout.py` | Вырезка автора из фона (RobustVideoMatting, ONNX, CPU) для текста за спиной. |

## Запуск

```bash
npm ci
npx tsx director/check-examples.ts
npx tsx director/direct.ts --input job/input.json --topic "Тема" --public public --media job --out out/job --sounds ../assets/astra/sounds
```

Для `direct.ts` нужны переменные:
- `CODEX_BRIDGE_TOKEN` (и при необходимости `CODEX_BRIDGE_URL`) — сервис Codex на Windows;
- `ASTRA_PYTHON` — Python с `onnxruntime` и `numpy`;
- `ASTRA_RVM_MODEL` — путь к `rvm_mobilenetv3_fp32.onnx`.

`input.json` — это `AstraInput` из `src/input.ts`: пути к видео внутри `public`, слова на очищенной дорожке, рамка лица.

## Версии правил монтажа и сравнение

На сайте доступны два самостоятельных стиля. «Астра» всегда выбирает прежний профиль `legacy`; «Астра v2» — `craft-v1`: адаптацию Emil Kowalski (движение), Taste Skill (композиция) и Impeccable (визуальная проверка) в `knowledge/craft-v1.md`. У v2 отдельные рабочая папка `astra-v2`, состояние `astraV2` и результат `out-astra_v2.mp4`. Старые результаты не перезаписываются. Правила загружаются при написании и проверке, ремонт ошибок сборки остаётся точечным. Для четырёх блоков проверка получает три фазы входа; вместе с обычными кадрами — не больше 22 кадров плюс раскадровка. Это выборочные кадры, а не просмотр непрерывного видео.

Старые правила доступны через `ASTRA_DESIGN_PROFILE=legacy` или `--design-profile legacy` у `director/direct.ts`. Для новой версии — `--design-profile craft-v1`. Профиль фиксируется на весь запуск и сохраняется в `design-profile.json` рядом с `system.md` и правками. Аргумент отдельного запуска имеет приоритет над переменной окружения. Для честного сравнения используйте одинаковую запись и расшифровку, два разных `--out` и `--media`; не передавайте `--start` (он повторно использует уже написанный монтаж), не отключайте review. Материалы и музыка могут различаться: сравнивайте их отдельно от оформления.

Бэкап до изменения: `../data/backups/astra-before-design-20261003/`. Он содержит текущие исходники движка, public-материалы, старую интеграцию `lib/astra`, `astraEngine.ts` и документацию, включая незакоммиченные изменения. `manifest.json` хранит SHA-256 файлов. node_modules и временные `.work` не копируются; зависимости восстанавливаются через `npm ci`. Записи и готовые ролики в `data/uploads` не изменялись. Для быстрого возврата к прежнему поведению используйте `legacy`; для полного восстановления исходников берите файлы из бэкапа, предварительно сохранив последующие изменения.

Оригиналы источников закреплены по commit в `knowledge/design-sources.json`, локальные копии — `../data/design-sources/`. Глобальные навыки Codex не устанавливались: правила встроены непосредственно в задания движка. В v2 установлен `hyperframes@0.8.114`: блоки Graphic рендерятся как локальные HTML/GSAP-композиции в прозрачный WebM, а Remotion собирает их с автором, субтитрами и звуком. Остальные блоки остаются в Remotion. Ошибка HyperFrames блокирует запуск, без скрытого переключения на другой движок. Для прямого запуска используйте `--design-profile craft-v1 --hyperframes`. Проверка настоящего рендера: `npx tsx director/hyperframes-smoke.ts`; она проверяет движение, прозрачность и итоговый MP4 без запроса к модели.

## Лицензии

- **Remotion** бесплатен для частного лица и компаний до 3 сотрудников. При большем штате нужна платная лицензия.
- **Шрифты** распространяются под лицензией OFL (`public/fonts/OFL.txt`).
- **RobustVideoMatting** — GPL-3.0. Модель работает внутренним инструментом и не распространяется.
- **Звуки и музыка** из Pixabay и Mixkit не хранятся в репозитории: их лицензии разрешают использовать файлы в роликах, но не раздавать их.
