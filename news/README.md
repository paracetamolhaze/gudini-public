# Новости — звуки и музыка

Папка раздела «Новости» на сайте. Код раздела — в ветке `news` (`news/engine`, `news/runner`); здесь только то, что
пополняешь ты сам.

- `music/` — фоновая музыка. Кидай сюда треки (mp3, m4a, wav): имя файла станет названием трека на сайте.
  Исполнитель на ПК сообщает сайту список при каждом запросе задания, и во вкладке «Монтаж» готового ролика
  можно поставить любой трек и посмотреть, с каким лучше. Новый ролик берёт первый трек по алфавиту.
- `sounds/<роль>/` — звуки монтажа, скопированы из библиотеки Астры (whoosh — склейки, swipe — смена кадра,
  pop — карточки и стоп-кадры, notification — комментарии, glitch, impact — удар, cash — деньги). Можно заменить
  своими: берётся первый файл папки.
- `voice/reference.mp3` — образец твоего голоса, который ты одобрил на слух: из нескольких дублей озвучки
  ролик берёт самый похожий на него.

- `features.json` — выключатели новшеств из каталога видео-скиллов (31.10): `false` выключает одно, не трогая остальные.
  sfxVariety — звуки одной роли по очереди; contentId — видеомемы на чужой музыке не предлагаются; qc и critic —
  проверка готового ролика и свежий критик (журнал исполнителя, папка qc/ задания); storyPlan — план истории и проверка
  штампов в тексте автора; marks, logoReveal, chats, numbers, maps — обводки, сборка логотипа, переписка, число, карта.
  Звуки `cc0-*` в папках ролей — из открытой библиотеки CC0 (откат — удалить их).

Аудиофайлы в git не попадают (`.gitignore`): лицензии разрешают ставить их в ролики, но не раздавать файлами.
