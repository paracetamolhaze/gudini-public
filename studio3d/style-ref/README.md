# Образец стиля для целевого кадра «3Д»

Сюда кладётся образец стиля от владельца: 1–3 кадра ролика, вид которого он хочет получить
(`.jpg`, `.png` или `.webp`, до 10 МБ каждый; берутся первые три по имени файла).

Что происходит с образцом (`director/dream.ts`):

- **Папка пустая** (как сейчас). Целевой кадр ключевого момента рисуется в возможностях текущего набора кубиков:
  GPT получает черновой кадр сцены и описание набора, меняется только постановка — крупность, поза, лицо, вещь
  в руке, экран, свет. Критик сравнивает кадр сцены с целью, режиссёр подтягивает план.
- **В папке есть картинки.** GPT получает черновой кадр как содержание и образец последним референсом —
  «только манера рисовки, ничего из содержимого». Цель выходит в стиле образца. Критик так же сравнивает её
  с кадром сцены, и всё, что набор воспроизвести не может, уходит в список «набору не хватает»:
  `dream/report.json` в папке задания и строка «Набору не хватает: …» в журнале исполнителя. Этот список —
  задание тому, кто делает кубики `src/kit`.

Образец читается при каждом задании: исполнителя перезапускать не нужно. Картинки в git не добавляются —
это файлы владельца, они живут в папке исполнителя.
